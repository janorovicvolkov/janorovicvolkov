### About

I maintain **[Liska Linux](https://liskalinuxproject.web.app)**, an independent distribution built around minimalism and user control. I work close to the system: core utilities, init scripts, shell automation, and the details that make a Linux system feel fast and dependable.

I'm currently exploring kernel development, package management, and boot optimization. When I'm away from low-level code, I'm probably tuning my terminal.
